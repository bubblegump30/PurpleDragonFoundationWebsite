# Security policy

## Scope and supported source

Security maintenance focuses on the current default branch and current
production website at https://www.purpledragonfoundationltd.xyz/ . Historical
snapshots and older source archives are not maintained release branches.
Downloadable applications linked by the website have their own repositories
and security policies; report product vulnerabilities to their maintainers.

## Report privately

Email **kyle@purpledragonfoundationltd.xyz** with a subject beginning
`[Security] Website report`. Do not open a public issue or pull request for an
undisclosed vulnerability. GitHub private vulnerability reporting may also be
used if the repository offers that option; its availability is not assumed.

Include the affected URL or source commit, a concise description, impact,
reproduction steps, and a minimal proof of concept if safe to share. Redact
tokens, credentials, personal data, and unrelated logs. Do not send malware,
large archives, or data belonging to other people.

The maintainer will assess the report and coordinate fixes and disclosure.
Response times vary; no response deadline, bounty, or reward is promised.
If you have not received a response, send a brief follow-up to the same address.
Please allow time for investigation before public disclosure.

## Responsible testing

Use your own local checkout where possible. Do not disrupt production, access
other people's data, phish users, run denial-of-service tests, or test linked
third-party services without their authorization. This policy does not grant
permission to access systems or bypass controls.
